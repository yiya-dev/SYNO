# SYNO Roadmap

## Phase 0 — Foundation

- Repository and documentation baseline
- C++/JUCE/CMake project skeleton
- VS Code workflow
- Coding and architecture conventions

## Phase 1 — Audio/MIDI core

- Audio device abstraction
- Real-time audio graph
- MIDI input/output
- Transport and tempo
- Basic metering

## Phase 2 — First DAW

- Tracks
- Timeline
- Clips
- Piano roll
- Mixer
- Automation
- Project save/load

## Phase 3 — Plugin platform

- VST3 discovery
- Plugin database
- Plugin hosting
- Plugin state serialization
- Missing-plugin recovery

## Phase 4 — Project persistence

- Stable `.syno` project identity
- Autosave
- Snapshots
- Versions
- Recovery

## Phase 5 — Synchronization

- Sync engine
- Local mirror model
- Private SYNO Server
- Incremental transfer
- Conflict detection and recovery

## Phase 6 — Cloud

- Hosted SYNO Cloud
- Device management
- Account and authentication
- Storage quotas
- Optional subscriptions later

## Phase 7 — Web DAW

- Browser project viewer
- Browser editing
- Shared project services
- Web-compatible audio core where practical
- Feature compatibility matrix

## Phase 8 — SYNO Native

- First-party instruments
- First-party effects
- Native preset format
- Portable deterministic plugin state

## Phase 9 — SynthOrdi

- Hardware control API
- Dedicated layouts
- Audio/MIDI integration
- Production hardware prototype

## Phase 10 — Ecosystem expansion

- Marketplace
- Collaboration
- Optional token integrations
- Additional hardware/software services
