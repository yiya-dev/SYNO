# SYNO Ecosystem

## SYNO DAW

The primary creative application. It hosts the audio engine, timeline, mixer, MIDI, automation, plugin system and project system.

## SYNO Server

Self-hosted software that stores projects and provides synchronization, authentication and version history.

## SYNO Cloud

A hosted service using the same logical APIs and project/sync model as SYNO Server.

## SYNO Web DAW

A future browser experience. It should consume the same project model and services rather than becoming a completely separate product.

## SYNO Tools

CLI and maintenance utilities for inspecting, repairing, converting, scanning and diagnosing projects and installations.

## Build Tools

Reproducible build, packaging, signing, release and CI helpers.

## SYNO Native

First-party synthesizers, samplers, drum machines and effects with native project-state integration.

## SynthOrdi

Dedicated hardware optimized for SYNO, potentially including touchscreen workflows, physical controls, audio I/O and integrated MIDI.

## SYNO Token

A separate future ecosystem/economic layer. It must remain optional for core music production functionality.
