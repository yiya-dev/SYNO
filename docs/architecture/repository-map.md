# Repository Map

```text
SYNO/
├── src/          Native SYNO DAW and shared runtime
├── server/       Self-hosted server
├── tools/        CLI and maintenance tools
├── build/        Build, packaging and release scripts
├── tests/        Automated tests
├── resources/    UI/assets
├── docs/         Vision, architecture and specifications
├── cmake/        CMake helpers
└── examples/     Examples of project data and APIs
```

The structure is intentionally broad at the start. Empty directories may exist only to reserve architectural boundaries; implementation should be added when needed.
