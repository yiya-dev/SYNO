# Project Lifecycle

A typical lifecycle:

1. Create a local project.
2. Work offline or online.
3. Autosave locally.
4. Create a snapshot when desired.
5. Synchronize changes to the configured mirror(s).
6. Continue on another device.
7. Restore an older version when necessary.
8. Archive the project without deleting its history.

The project should survive the loss of any single device.
